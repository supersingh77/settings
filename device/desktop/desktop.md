# Desktop layout

This file records placement rules, not the current contents of the user's Desktop folder.

- Keep the desktop root for active folders and shortcuts; put installers, archives, and generated reports elsewhere.
- Keep finance records in their existing folders. Do not add a catch-all folder for personal documents.
- Keep daily-use apps on the taskbar and use desktop shortcuts only when they have a clear purpose.
- Current taskbar pins are generated in [`startmenu-taskbar.md`](startmenu-taskbar.md). Verify Start menu changes visually.
