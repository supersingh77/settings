## Custom AHK Scripts (`scripts/`)

| Script | Action | How to run |
|--------|--------|-----------|
| `scripts/disable-scroll.ahk` | Blocks mouse wheel up/down (faulty Logitech scroll wheel workaround) | `autohotkey scripts/disable-scroll.ahk` or double-click |
| `scripts/enable-scroll.ahk` | Kills the disable-scroll script and restores scrolling | `autohotkey scripts/enable-scroll.ahk` or double-click |
| `scripts/enable-autostart.ahk` | Adds a startup shortcut so `disable-scroll.ahk` runs on every login | double-click once |
| `scripts/disable-autostart.ahk` | Removes the startup shortcut | double-click once |

**Quick toggle:** `scripts/disable-scroll.ahk` also responds to **Ctrl+Alt+Q** to exit.
