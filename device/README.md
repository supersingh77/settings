# Devices

This folder holds what is left of the pre-`dev` tooling: the Windows laptop's scripts and the desktop media utilities.

| Machine | State | Notes |
|---|---|---|
| Windows desktop | `devices/desktop/` | `notes/desktop-*.md`, media utilities under `desktop/` |
| Windows laptop | `laptop/` until phase 5 | its own scripts and inventories |
| Fedora laptop | `devices/fedora-laptop/` | `notes/fedora-port.md`, `notes/silverblue-system.md` |
| Phones | `devices/phone-personal/`, `devices/phone-work/` | `notes/phone-connection.md` |

The Windows desktop and Fedora laptop use the `dev` tool; the phones are captured over adb from the Fedora laptop.
