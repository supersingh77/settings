# Redmi Note 11 phones

Shared model facts are in [`hardware.md`](hardware.md). The work and personal
units have separate current snapshots under [`work/`](work/) and
[`personal/`](personal/). Phone capture runs through the Fedora laptop's
`laptop phone` command and updates the device state section plus package lists.

USB debugging is normally off for banking-app security. Enable it only while
capturing or managing a phone. The work phone remains on stock MIUI with a
locked bootloader; do not flash a ROM without verified variant-specific
installation and recovery instructions.
