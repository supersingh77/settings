# Desktop layout rules

> Device: desktop

- Keep the desktop root for active folders and shortcuts; put installers, archives and generated reports elsewhere.
- Keep finance records in their existing folders. Do not add a catch-all folder for personal documents.
- Keep daily-use apps on the taskbar; use desktop shortcuts only when they have a clear purpose.
- Taskbar pins are observed state; Start menu pins are not captured, so check them by eye after a change.
