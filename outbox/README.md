# Outbox

Agent's outgoing work — ready to dispatch to another chat, app, or agent.

One `.md` file per item. When it's ready to send, it goes here. When it's sent, it's removed.

```md
# Short title

> Created: YYYY-MM-DD
> Target: [which chat/app/agent]
> Status: ready-to-send

## What needs to happen

[Description]

## Payload

[The actual content]

## Next action

[What to dispatch it]
```
