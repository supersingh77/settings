# Inbox

Drop new, unsorted details here. One small Markdown file per topic is enough.

```md
# Short title

> Device: desktop / laptop / phone / shared
> Added: YYYY-MM-DD

## What to remember

## Useful links, paths, or commands

## Next action (optional)
```

Move the note only when it has an obvious long-term home. It is fine for the inbox to stay messy.
